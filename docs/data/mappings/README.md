# Mappings de sources

Un fichier par source décrivant le mapping utilisé (conforme au contrat `PLAN.md` §5.1).

> À produire : `tracelab.md` (I2.11) et `swe-chat.md` (I2.12) — deux sources distinctes minimum.

Chaque fiche contient : format source, version/date du dataset, correspondances champ source →
champ cible + transformation, champs non mappés (`unmapped_fields`) et pourquoi, résultat du test
bout-en-bout sur l'extrait réel.
